122 файла с именами `tmp-*`, `_tmp*` и бинарными дампами уже перенесены в обратимый `backup/maintenance-quarantine`. Рабочий аудит после операции показывает 0 кандидатов.

## Правила дальнейшей обработки

1. Нельзя массово перемещать `apply-*`, `fix-*`, `emergency-*` и rollback-скрипты: они могут быть единственным способом восстановления production.
2. Перед архивированием для каждого скрипта фиксируются назначение, дата последнего запуска, затрагиваемые серверы, dry-run и rollback.
3. Новые временные скрипты запрещены CI-проверкой `npm run check:repository`.
4. Новые изменяющие production-скрипты должны использовать lock, явный target, preflight и подтверждение.
5. Автоматические cron-задачи должны ссылаться только на отслеживаемые Git production/maintenance-скрипты.

## Следующая безопасная консолидация

- объединить read-only команды в `scripts/diagnostics/`;
- перенести завершённые миграции в `scripts/archive/YYYY-MM/` только после проверки cron и документации;
- оставить deployment и rollback парами;
- не удалять quarantine до окончания периода наблюдения 14 дней.
